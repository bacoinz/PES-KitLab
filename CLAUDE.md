# PES KitLab (antes PES Kit Creator)

Criador de equipamentos portátil para Windows para o **SP Football Life 2027** (base PES 2021, Sider 7.3.3).
Lê as equipas do jogo, edita ou cria kits com pré-visualização 3D, gera em massa e exporta para o Sider kit-server.
O utilizador fala português de Portugal: a UI e as respostas são em PT-PT.

> **Manter este ficheiro atualizado:** sempre que o projeto mudar (código, estrutura, comandos, formatos, decisões),
> atualiza a secção correspondente e acrescenta uma linha ao **Histórico** no fim.

## app-tauri

- `src-tauri/src/lib.rs` — comandos Tauri (mesmos nomes que `src/shared/ipc.ts`, em snake_case), estado, `launch_game`, modo de script `KC_SCRIPT`.
- `src-tauri/src/game/` — `cpk.rs` (CRI CPK, @UTF, CRILAYLA), `wesys.rs`, `tex.rs` (FTEX/DDS; descodifica com `texture2ddecoder`, codifica BC7/DXT com `intel_tex_2` em paralelo com `rayon`), `fmdl.rs`, `index.rs` (índice das CPKs + raízes livecpk), `teams.rs` (Team/Country/Competition.bin, `fl26world.txt`), `kitserver.rs` (map.txt, config.txt, order.ini).
- `src-tauri/src/store.rs` — exportação, versões (snapshots), ativar/repor original, zips, emblemas. Tamanho da textura exportada: definição `exportSize` (512/1024/2048/4096, Biblioteca) usada em `exportProject` (`state.ts`); o `tex.rs` codifica qualquer tamanho.
- `src/kc.ts` — `window.kc` sobre `invoke`. Binários: respostas cruas `[u32 w][u32 h][rgba]`; envios grandes num corpo `[u32 len][JSON][blobs]`.
- `src/compositor/gpu.ts` — compositor WebGL2: passes `fill` (sólido/gradiente + máscara + máscara2), `image` (logo com tinta/P&B/contorno), `rgba`, `tile`; mapa de regiões por texel; máscaras em cache (LRU).
- `src/compositor/compose.ts` — `KitDesign` → passes. Camadas: `withMirror` (inverter / espelho ao centro / espelho nas costas), `blurred` (desfoque da máscara; imagens desfocadas em `blurredImg`); o shader em `gpu.ts` tem os 16 modos de mistura (`BLENDS`). Camadas `kind:'panel'` (`drawPanel`): painéis desenhados direto no espaço da textura ao longo das costuras (laterais, ombro, gola, bainha/faixa dos calções, dobra/remate das meias); medidas em `uv.ts` (`PANEL`, `NECK_HOLE`, `SLEEVE_SEAMS`). Padrão personalizado = camada imagem com `fit:'tile'` (`tileCell`; cores originais → `tileRgbaPasses`, uma passagem RGBA por zona; uma cor → caminho de máscara). Desenho livre = `kind:'freeform'` com `strokes` em px da textura (`drawStrokes`); pincel 🖌 (B) no `TexView` (`onBrush`), traço confirmado no fim = 1 passo de anular. `composeLive` (canvas GL partilhado com o viewer), `composeRgba` (exportação), `composeKit` (cópia 2D para miniaturas). Referenciais de peça: `PART_FRAMES` (calções/meias), `SLEEVE_FRAMES`.
- `src/compositor/uv.ts` — layout UV 2048² (medido nos modelos Comet = igual ao jogo): regiões, `SHORTS_FRAME`, `SOCK_FRAME`, `LEGS`, `SPOTS`, `sleeveSeam` (costura do sovaco: logos das mangas que passam uma aresta continuam na outra).
- Brilho (só pré-visualização 3D): `shine` no kit (rugosidade única do material) e `shine` por camada → `composeShine` gera um mapa de rugosidade 512² que o viewer usa como `roughnessMap`.
- `src/compositor/template.ts` — **template 2D = `KIT Template.png`** (copiado para `public/kit-template.png`): as peças são os pixels não transparentes, exceto as duas caixas de nota em baixo (x 461–659 e 1388–1586, y ≥ 1905: notas de design que só existem no FTEX); a vista 2D pinta o fundo fora delas e desenha os contornos. Igual para todos os kits (braçadeira e manga comprida não mudam o 2D).
- `src/three/KitViewer.tsx` + `comet.ts` — viewer com os GLB Comet (`public/models/*.glb`, `models.json`); só o kit (sem braços/corpo). Câmaras `CAMS` (frente, costas, lados, ¾ esq./dir./costas, mangas, gola, calções, meias), rotação automática (`autoRotate`) e `snapshot` (PNG da vista 3D, fundo transparente). `uvIslands()` (ilhas UV dos modelos; já não usado pela vista 2D). Tone mapping Neutral (cores fiéis) e controlo "Luz" (exposição). Menu "⚙ Vista" (fase G): 12 predefinições de luz (`LIGHT_PRESETS`/`LIGHTS`: exposição, força do ambiente, luz principal e de enchimento), ambiente (`envScene`: interior, estúdio claro, exterior), fundo (transparente ou cor), esconder calções/meias e camisola por dentro; guardado em localStorage (`kc.v3.*`).
- `scripts/export_comet_glb.py` — exporta os GLB a partir do `.blend` Comet (Blender 4.2 portátil). As malhas do template vêm partidas nas costuras UV: o script solda-as antes da subdivisão (`_sd.glb`), senão abrem rasgos/estrelas.
- Interface de camadas (fase A, ver `docs/interface-camadas.md`): `layerList(part, fixed)` em `Editor.tsx` — linhas compactas (a de cima fica por cima, arrastar = `dropLayer` em `design.ts`, largar num membro junta-o ao grupo, largar numa linha fixa manda para o fundo), linhas fixas (Tecido, Gola, Mangas, Braçadeira, Base; calções/meias: Base…) e grelha "Adicionar camada" (inclui painel `cuffs` = Punhos). `ColorPicker.tsx`: seletor de cor (grelha, predefinições kit/equipa/guardadas/cores comuns, quadrado S/V, matiz, hex, conta-gotas, Aplicar a todos via `ColorCtx`); `ColorInput` usa-o em toda a app. `icons.tsx`: ícones SVG.

## Comandos (em `app-tauri/`)

```bash
npm install
npx tsc --noEmit                      # typecheck da UI
cd src-tauri && cargo test --release  # testes Rust (os de integração usam o jogo real, só leitura / cópia temporária)
npx tauri build --no-bundle           # exe de release em src-tauri/target/release/
npm run dist                          # sobe a versão (patch), compila e copia para dist-portable/PES-KitLab-<versão>-portable.exe (apaga os exe das versões anteriores)
npm run dist:same                     # igual, sem subir a versão
```

Rust está em `%USERPROFILE%\.cargo\bin` (acrescentar ao PATH na shell). Escrever ficheiros de texto sem BOM (o PowerShell 5 `Set-Content -Encoding utf8` mete BOM e parte o `package.json`).

### Verificação automática da UI
`KC_SCRIPT=passos.json` (+ `KC_DATA=<pasta com KitCreatorData>`) arranca a app, corre passos `{ "wait": ms, "js": "...", "shot": "ficheiro.png", "quit": true }` e escreve os resultados em `passos.json.log`. Ganchos: `window.__kc` (store), `window.__kcTest` (composeKit/Live/Rgba…), `window.__kcView(pos, alvo)` (câmara).

## Regras do projeto

- O KitCreator **só escreve o que é seu**: a sua secção no fim de `map.txt` (entre `# ---- KitCreator (do not edit by hand) ----` e `# ---- end KitCreator ----`; no kits.lua a última entrada ganha), as pastas `content\kits\KitCreator\<Liga>\<Equipa>\`, a raiz `livecpk\KitCreator` (emblemas) e uma linha `cpk.root` no `sider.ini`. Cópias originais em `KitCreatorData\backups`. Repor original = apagar o que é nosso.
- Dados portáteis em `KitCreatorData\` ao lado do exe (em debug: `app-tauri/KitCreatorData`, ou `KC_DATA`).
- O 2D é a fonte; o 3D só embrulha. Logos ficam direitos no 2D, no referencial de cada ilha UV (patrocínio do rabo atravessa a costura `bumSeam` nas duas pernas).
- Git (repositório privado `PES-KitLab` no GitHub): **fazer commit e push só quando sai uma versão menor nova** (0.4, 0.5, …), não nas 0.x.y intermédias; fora disso só a pedido.
- O email do utilizador é privado.
